Third assignment : Projects & Project Memberships

Description: This project extends Programming Assignment 2 (PA2), a full-stack login and signup application, by adding project management and project membership functionality.

The application allows users to register and log in, create software projects, view existing projects, select a Project Lead from registered users, and manage the members of each project.

The frontend is built with React, the backend uses Node.js and Express, and MongoDB stores the application data.


Instructions: 

A. Sign Up

-Enter your first name, last name, username, and password in the Sign Up form.

-Click Create Account.

-Read the message displayed by the application to confirm whether registration succeeded.

-Usernames must be unique.



B. Log In

-Enter your registered username and password in the Login form.

-Click Login.

-Check the displayed message to see whether the credentials were accepted.



C. Create a Project

-Locate the Create Project form.

-Enter the project name and description.

-Select a status: Planning, Active, or Completed.

-Choose a registered user from the Project Lead dropdown.

-Click Create Project.

-Check the confirmation message and the View Projects section.

The selected Project Lead is automatically added to the project's membership list.



D. View Projects

The View Projects section displays existing projects, including:

Project name,Description,Status,Project Lead's name and username

Click Refresh Projects to reload the project list.



E. Manage Project Memberships

-Navigate to Manage Project Memberships.

-Select a project from the project dropdown.

-Review the users listed under Current Members.

-To add a member, select a registered user in the Add Member dropdown and click Add Member.

-To remove a member, click Remove Member beside a non-lead member.
